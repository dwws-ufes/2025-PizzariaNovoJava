💡 Exemplos de Consultas SPARQL

Todos os produtos:

PREFIX schema: <http://schema.org/>

SELECT ?produto ?nome ?descricao ?preco ?tipo WHERE {{ "{" }}
        ?produto a schema:Product ;
               schema:name ?nome ;
               schema:description ?descricao ;
               schema:price ?preco ;
               schema:category ?tipo .
        {{ "}" }}
        ORDER BY ?tipo ?nome

Produtos por tipo:

PREFIX schema: <http://schema.org/>

SELECT ?produto ?nome ?descricao ?preco WHERE {{ "{" }}
        ?produto a schema:Product ;
               schema:name ?nome ;
               schema:description ?descricao ;
               schema:price ?preco ;
               schema:category "0" .
        {{ "}" }}
        ORDER BY ?nome

Busca por nome:

PREFIX schema: <http://schema.org/>

SELECT ?produto ?nome ?descricao ?preco ?tipo WHERE {{ "{" }}
        ?produto a schema:Product ;
               schema:name ?nome ;
               schema:description ?descricao ;
               schema:price ?preco ;
               schema:category ?tipo .
        FILTER(CONTAINS(LCASE(?nome), LCASE("margherita")) ||
               CONTAINS(LCASE(?descricao), LCASE("margherita")))
        {{ "}" }}
        ORDER BY ?tipo ?nome
