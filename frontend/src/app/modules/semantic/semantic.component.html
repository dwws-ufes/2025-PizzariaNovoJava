💡 Exemplos de Consultas SPARQL

Todas as pizzas com links para DBpedia:

PREFIX schema: <http://schema.org/>
PREFIX pizzaria: <http://localhost:8081/pizzaria/>

SELECT ?pizza ?nome ?preco ?dbpedia WHERE {
        ?pizza a pizzaria:Pizza ;
               schema:name ?nome ;
               schema:price ?preco .
        OPTIONAL { ?pizza schema:sameAs ?dbpedia }
}

Pedidos com detalhes do cliente:

PREFIX schema: <http://schema.org/>
PREFIX pizzaria: <http://localhost:8081/pizzaria/>

SELECT ?pedido ?clienteNome ?dataHora WHERE {
        ?pedido a pizzaria:Pedido ;
                schema:customer ?cliente ;
                schema:orderDate ?dataHora .
        ?cliente schema:name ?clienteNome .
}
